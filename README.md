# Hack Day Swap

## Run

From this folder, run `python3 -m http.server 8000` and open http://localhost:8000.

## Play

Tap a mismatched token to select its connected colour group. Tap the memory
tray to lift as many selected tokens as fit. Then tap a socket matching the
first tray colour. If that socket is occupied, its old token returns to the
tray. Fill every socket and empty the tray to restore the robot.
